开始使用

三步把代理跑起来。每一步只做一件事，做完自动进入下一步。

✓导入节点4 个节点就绪
›
2选择主节点决定默认出口
›
3启用服务起来并自检

导入节点

从订阅地址批量导入，或粘贴一条分享链接。

导入的节点归到该订阅分组；更新时只动这个分组，不影响手工节点。
或粘贴分享链接
vless / vmess / trojan / ss / hysteria2 / tuic / anytls …

启用服务

启动前会先生成配置并交给 sing-box 自检；不通过就不会启动，正在跑的配置继续用。

开机自启
路由器重启后自动拉起
IPv6 支持
关闭时强制走 IPv4，避免部分节点不可达
代理局域网设备
关闭时只代理本机
✓
自检通过后会把这份配置记为 known-good；之后某次改动导致健康检查失败，会自动回滚到它。
高级设置（分流 / DNS / 服务端 / 证书 / 资源库）
⚠
高级项改动会立即重载服务。若自检失败，界面会保留原配置并告诉你失败原因。
